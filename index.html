Experiencia en análisis operativo y seguimiento de requerimientos utilizando Google Sheets avanzado (funciones QUERY, filtros y referencias cruzadas) para optimizar métricas e indicadores de gestión[cite: 1].

Formación complementaria en análisis exploratorio de datos con Python (SENA), fundamentos de SQL (Simplilearn) y conexión a bases de datos con MongoDB (Mongo University)[cite: 1].
